# ClashKing Translations

Planning and future home for shared translation catalogs, the contributor website and localization workflows across ClashKing Bot, App, Dashboard and API.

## Status

Discovery only. No translation runtime, hosting stack or canonical format has been selected, and no existing catalogs have been migrated.

## Plan

Start with https://github.com/ClashKingInc/ClashKingTranslations/issues/1.

- [Choose the shared message format and catalog ownership](https://github.com/ClashKingInc/ClashKingTranslations/issues/2)
- [Design an embeddable translation editor using ClashKing accounts](https://github.com/ClashKingInc/ClashKingTranslations/issues/3)
- [Define contributor approval, abuse controls and safe AI review](https://github.com/ClashKingInc/ClashKingTranslations/issues/4)
- [Plan validation and release workflows for translation bundles](https://github.com/ClashKingInc/ClashKingTranslations/issues/5)
- [Plan incremental migration and independent translation updates in every consumer](https://github.com/ClashKingInc/ClashKingTranslations/issues/6)

The intended contributor experience reuses ClashKing Discord/email accounts and supports contextual translation, review and independent translation releases. Decisions about approvals, AI assistance, compatibility and rollback are part of the plan.
